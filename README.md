# Kristina Noriega Professional Portfolio

A curated professional portfolio for Dr. Kristina M. Noriega highlighting:

- Human-Centered AI and research-support systems
- Learning analytics and Tableau
- Behavioral and UX research
- Learning measurement and evaluation
- Digital learning systems and deployed applications
- Learning experience design

## Deploy on Render

1. Create a new GitHub repository, recommended name:
   `Kristina-Noriega-Portfolio`
2. Upload all files from this folder to the repository root.
3. In Render, choose **New > Blueprint** and connect the repository.
4. Render will read `render.yaml`.
5. Recommended service name:
   `kristina-noriega-portfolio`
